## **ii. What is MCP?**

---

The **Model Context Protocol (MCP)** defines an open standards interface for connecting large language model (LLM) applications to external systems. Before it existed, wiring an LLM to an external tool meant building a custom connection layer for each potential endpoint — a significant, inconsistent level of effort that varied across teams and organizations. MCP replaces those old methods with a single protocol, both-sides implementation: *once a service offers an MCP server, any MCP-compatible client (Bob included) can connect to it immediately, with no custom integration work.*

MCP originated at Anthropic and has since been transferred to the **Linux Foundation**, making it a vendor-neutral, *openly governed standard*. This governance, more than anything else, is what has accelerated its widespread adoption across the industry. Most major external services and developer tools now ship MCP servers, creating an extensive ecosystem of ready-to-use integrations.

---

MCP servers are configured in Bob's settings through a JSON configuration file.

The simplified flow is as follows:

1. Open Bob settings via the three-dot menu (**⋯**),
2. Navigate to **MCP Servers**
3. Add the server configuration in JSON
4. Supply credentials as required

Most services publish their own configuration snippets within their official documentation. Furthermore, Bob itself can insert the JSON for you, handling indentation and brackets automatically.

How you handle credentials is a governance decision in itself:

| METHOD | DESCRIPTION | USE CASE |
|--------|-------------|----------|
| **Inline with config** | Personal access token written directly in the JSON file | Quick setup, local development only |
| **Environment variable** | Token stored as an OS environment variable, referenced in config | Cleaner setup, avoids token in config file |
| **Context forage** | Open source MCP gateway for managing complex, multi-server setups | Teams, production environments, multiple credentials |

!!! quote "USING MCP TOOLS"

    **MCP tools** are available only in Bob's **Agent Mode**. With Agent Mode active, Bob automatically recognizes the tools exposed by every configured server and invokes them in response to natural-language requests.

    No special syntax is quired required. Bob simply decides which MCP tools to call based on the task you describe.

    The GitHub MCP server shows how much a single integration can add:

    - *Configuration:* paste GitHub's configuration snippet into the JSON config, then add a personal access token whose permissions match the operations Bob will perform (reading issues, creating commits, adding comments, closing issues)
    - *Agent Mode capabilities enabled:* with Agent Mode active, Bob can list and read issues, create commits and push changes, add comments, close issues, and link commits to issues
    - *Testing:* a token with insufficient permissions will simply cause the affected operation to fail and Bob will report the permission error so that you know to update the token

    Strung together, Bob's Agent Mode capabilities make a complete **issue-resolution loop** possible entirely through natural language expressions. A full development cycle— from issue to closed resolution —is possible, without ever leaving the Bob interface:

    - *Ask* Bob to list open issues (Bob will call the GitHub MCP tool to retrieve them)
    - *Describe* the one issue to fix (Bob reads the relevant code and implements the change)
    - *Instruct* Bob to commit and push the fixed code (Bob calls the right MCP tools and git commands)
    - *Comment* (via Bob, at your behest) on the issue with a link to the commit and close the issue.

    And GitHub is just one server in a fast-growing ecosystem that already spans version control and code review platforms, project management and issue-tracking tools, databases and data services, cloud infrastructure providers, and internal enterprise systems. In practice, most of the external integrations a development team relies upon can be connected to Bob through MCP, with no custom development required.
