## What is IBM Bob?

IBM Bob is an AI-powered software development lifecycle (SDLC) partner that integrates directly into the development environment. Bob operates across the full development lifecycle — not just as a code generator, but as a partner that supports planning, implementation, and automation throughout a project.

Bob's core capabilities:

- **Code writing and modification**: Writes new code and modifies existing code across the entire codebase based on natural language instructions
- **Codebase understanding**: Reads and reasons about complex project structures, dependencies, and architectural patterns
- **Development task automation**: Automates repetitive tasks such as documentation, commit message generation, and test scaffolding

---

## Bob as an SDLC Partner

The distinction between Bob and a traditional code generator is scope. Bob is designed to support the entire software development lifecycle, not just the moment of writing a function or fixing a bug. This includes:

- Helping plan features before implementation begins
- Understanding the full context of a project before making changes
- Keeping the developer in control at every step

Bob augments existing workflows rather than replacing developer judgment.

---

## Interfaces

Bob is available in two primary form factors:

| Interface | Description |
|-----------|-------------|
| **Bob IDE** | VS Code extension providing an agentic sidebar, inline code assistance, and mode-based interaction |
| **Bob Shell** | Terminal-based interface offering the same capabilities in a keyboard-driven, automation-friendly form factor |

## Learning Path Structure

This learning path covers IBM Bob across five chapters:

| Chapter | Focus |
|---------|-------|
| 1 | Demo setup and environment introduction |
| 2 | Core interaction patterns: tab completion, next edit prediction, and the agentic chat |
| 3 | Customization: project context, custom rules, and custom modes |
| 4 | Advanced topics: context window management and Bob Shell |
| 5 | Extending Bob's capabilities with the Model Context Protocol (MCP) |

Each chapter builds on the previous, progressing from basic interactions to advanced configuration and integration.

## Key Takeaways

- Bob supports the full software development lifecycle, not just code generation
- Two interfaces are available: Bob IDE (VS Code) and Bob Shell (terminal)
- The developer remains in control — Bob assists with reasoning and implementation, but does not replace developer judgment
- This learning path progresses from beginner to advanced topics across five chapters
