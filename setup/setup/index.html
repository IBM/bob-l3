    RESERVING AND PREPARING YOUR ENVIRONMENT

    i. IBM Bob Registration & Approval Process

    There are currently two primary methods to acquire authentication for IBM Bob. Each have their pros and cons...

    Trial Version

    • Skip to OPTIONAL Chapter 0.1 - Trial (and disregard Optional chapters 0.2 and 0.4)
    • Approval takes under 10 minutes.
    • Must use a NON-IBM email address to register (IBMers can still use the Trial version, just use a personal address)
    • 40 Bobcoins (more than enough for this lab)

    Internal Version

    • Skip to OPTIONAL Chapter 0.2 : Internal Registration (Local Machine) (and disregard Optional chapters 0.1 and 0.4)
    • Approval takes 24+ hours.
    • Lasts indefinitely
    • 100 Bobcoins (linked to your w3id, so if you hit your balance limit doing other tasks outside of this lab, the restriction still applies - devs who hit their limit can register for the Trial version with a personal email)

    I already have IBM Bob

    • Skip to Chapter 0.3 : Access Galaxium Travels Demo App Locally and ignore the Optional chapters. If you jump here, this assumes you have already installed and authenticated IBM Bob before this L3 course.

    To summarize:

    • if you are under time constraints, have previously maxed your Bobcoin balance, and/or are a Business Partner, get the Trial version. (IBMers can use the Trial version too, although the Internal version is the official reccomendation)
    • If you aren't in any rush, want to do additional exploration with Bob outside of this lab content, and/or are an IBMer, use the Internal version.
    • If you've already used IBM Bob before, your account is likely already created and you can proceed with it. - jump to Chapter 0.3

    If you want to complete this Level 3 course as quickly as possible, I suggest you just use the Trial version to avoid having to wait for manual approval.

    Chapter 0.3: Install Galaxium Travels Demo App

    1. If you don't already have them, download Python and Node.js.
    • Python 3.8+ - Download
    • Node.js 18+ - Download
    • npm (comes with Node.js)
    1. Open a terminal window and paste the command:

    git clone -b bob-learning-path-branch https://github.com/IBM/galaxium-travels

    ...and execute it.

    1. In a Terminal window, move to the galaxium travels directory.

    On Windows, paste:

    cd $HOME\galaxium-travels

    On Mac, paste:

    cd ~/galaxium-travels

    ...and execute it.

    Chapter 0.3.1: Access Galaxium Travels on Mac or Linux Locally

    Starting up the app is simple on Mac and Linux machines...

    1. On Mac or Linux, paste:

    ./start.sh

    ...in the terminal window, and press Enter.

    One-line startup above not working?\ Here is the manual process. Execute each command separately, and open a new terminal window when directed (for frontend startup).

    Start Backend:

    cd booking_system_backend
python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate
pip install -r requirements.txt
python server.py

    Start Frontend (in a new terminal):

    cd booking_system_frontend
npm install
npm run dev

    1. We can see that the app has successfully started. To access it, let's copy the URL so we can access the frontend- it should look like:

    http://localhost:5173

    1. Return to your web browser.

    1. Paste the address we just copied in the search bar:

    http://localhost:5173

    ...and press Enter

    1. We have now successfully accessed the front end of the demo application, Galaxium Travels.

    1. Return to IBM Bob and click Explorer (or press Ctrl+Shift+E)
